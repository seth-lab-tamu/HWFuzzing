# HyPFuzz

This directory is the development location for HyPFuzz. The current `demo/`
directory provides a simplified example of HyPFuzz's basic functions using the
CVA6 processor.

> **Version note:** This demo is based on **Chipyard 1.7.1**. It is **not**
> based on Chipyard 1.13.0. Paths, generated RTL, tool commands, and coverage
> data may differ in newer Chipyard releases.

## What the demo shows

HyPFuzz combines coverage-guided fuzzing with formal verification. The demo
illustrates how to:

1. Parse a VCS coverage database and the DUT hierarchy.
2. Identify uncovered branch-coverage points and recover the conditions needed
   to cover them.
3. Compare fuzzing and formal-verification coverage rates to decide when to
   switch to formal verification.
4. Select uncovered points using the Random, MaxUncovd, ModDep, TopBot, and
   BotTop strategies.
5. Convert selected coverage conditions into SVA cover properties for
   JasperGold.

The demo is intentionally simplified and does not contain every component of
the complete HyPFuzz workflow.

## Commercial-tool-generated files

Some inputs and reports are generated by commercial EDA tools and are
intentionally **not uploaded to this repository**. In particular:

- `demo/cov_html/` is the human-readable VCS coverage report.
- `demo/cov_xml/` is the VCS XML coverage database parsed by the Python demo.

These directories must be generated with an appropriately licensed VCS
installation. If you want to execute the complete parsing flow, place the
generated directories at the paths above. The expected XML layout includes:

```text
demo/cov_xml/snps/coverage/db/design/verilog.design.xml
demo/cov_xml/snps/coverage/db/testdata/test/
demo/cov_xml/snps/coverage/db/shape/
```

`cov_html/` is useful for manually inspecting and validating coverage results,
but it is not consumed by the Python scripts. `cov_xml/` is required to rerun
coverage parsing and regenerate the derived files. Precomputed CSV, XLSX, and
JSON examples are included so that the output formats and point-selection data
can still be examined without uploading the commercial-tool-generated reports.

JasperGold setup files are provided only as an example and require a licensed
JasperGold installation to use.

## Running the Python demo

The scripts expect Python 3 with `pandas` and an Excel reader such as
`openpyxl`. After generating and placing `cov_xml/` as described above, run:

```bash
cd demo
python3 HyPFuzz.py
```

Run the command from `demo/`, because the script resolves its inputs relative
to the current working directory. It regenerates the module-ranking CSV files
and `uncovd_point.json`, then prints the switching decision, selected uncovered
points, and their generated cover properties.

For more detail about the example output and JasperGold setup, see
`demo/ReadMe.pdf`.
